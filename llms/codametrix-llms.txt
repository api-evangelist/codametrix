# CodaMetrix

> CodaMetrix is a Boston-based healthcare AI company whose CMX CARE platform performs autonomous medical
> coding — translating clinical documentation into billing and diagnostic codes without human touch. Spun
> out of Mass General Brigham's physician billing organization in 2019, it is delivered as an AWS-hosted
> SaaS integrated directly into the EHR (Epic Toolbox member, plus Cerner, Meditech and GE) rather than as
> a public developer API. The only publicly callable API CodaMetrix operates is the unauthenticated status
> API at status.codametrix.com.

This file was generated by API Evangelist from the CodaMetrix public surface. CodaMetrix publishes no
llms.txt of its own (https://www.codametrix.com/llms.txt returns 404). Its robots.txt explicitly allows
GPTBot, ClaudeBot, Claude-SearchBot, Claude-User, OAI-SearchBot, ChatGPT-User, PerplexityBot,
Perplexity-User and Google-Extended, with no differential treatment of AI agents.

## APIs

- [CodaMetrix Status API](https://status.codametrix.com/api/): Unauthenticated JSON status API (Atlassian Statuspage Page API v2). Eight read-only GET endpoints under https://status.codametrix.com/api/v2/ — page summary, status rollup, component tree, incidents (all and unresolved), scheduled maintenances (all, upcoming, active).

## Endpoints

- https://status.codametrix.com/api/v2/summary.json — everything in one call (recommended)
- https://status.codametrix.com/api/v2/status.json — indicator: none | minor | major | critical
- https://status.codametrix.com/api/v2/components.json — CMX Automate, Analytics Dashboards, CMX-Amplify
- https://status.codametrix.com/api/v2/incidents.json — 50 most recent incidents
- https://status.codametrix.com/api/v2/incidents/unresolved.json — open incidents only
- https://status.codametrix.com/api/v2/scheduled-maintenances.json — 50 most recent windows
- https://status.codametrix.com/api/v2/scheduled-maintenances/upcoming.json — scheduled state only
- https://status.codametrix.com/api/v2/scheduled-maintenances/active.json — in progress or verifying
- https://status.codametrix.com/history.atom — incident history, Atom
- https://status.codametrix.com/history.rss — incident history, RSS

## How to call it

- No authentication. No API key. CORS is fully open (`access-control-allow-origin: *`).
- Responses are `application/json` with `cache-control: max-age=10` and a weak `ETag`. Poll no faster than
  every 10 seconds and prefer `If-None-Match`.
- No pagination. The incidents and scheduled-maintenances collections are hard-capped at 50 records.
- No error envelope. An invalid path returns a bare HTTP 404 with an empty body. An empty `incidents` or
  `scheduled_maintenances` array is the healthy state, not a failure.
